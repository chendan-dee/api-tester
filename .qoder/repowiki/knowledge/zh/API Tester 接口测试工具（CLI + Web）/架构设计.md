模块按职责拆分为四个层次：
- 入口层：`runner.py` 作为 CLI 入口，解析 `--config/--step` 参数后调用 engine；`app.py` 是 Flask Web 服务，暴露 `/api/*` REST 接口并托管 `templates/index.html`。
- 业务核心层：`engine.py` 集中实现所有测试逻辑——HTTP 请求（`requests`）、断言（状态码/body/json_path/response_time/header_contains）、变量提取（`get_by_path` 支持 `[0].id` 路径）、setup 前置条件（白名单 eval）、mock 响应、结果保存（pandas xlsx → csv 回退），对外仅暴露 `run_single` / `run_steps` 两个公开函数。
- 表现层：`printer.py` 封装全部终端输出（colorama 彩色标记），被 engine 通过 `import printer as P` 统一调用，使 Web 端可通过 `contextlib.redirect_stdout` 捕获控制台文本。
- 辅助工具层：`curl2yaml.py` 解析 `cases/curl.txt` 生成单接口 YAML；`yaml_checker.py` 对 YAML 结构做深度校验（方法白名单、必填字段、类型检查）并提供友好修复建议；`启动.bat` 自动安装依赖并启动 `app.py:5050`。
依赖方向单向：runner/app → engine → printer；app 额外依赖 yaml_checker、curl2yaml；数据文件集中在 `cases/`（YAML 用例）、`templates/`（前端页面）、`temps/`（临时脚本）。
