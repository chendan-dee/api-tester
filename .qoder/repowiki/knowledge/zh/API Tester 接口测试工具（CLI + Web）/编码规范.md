- 引擎函数返回统一的字典记录（含 status_code/elapsed_ms/passed/断言消息等），由 save_result 统一序列化为 xlsx/csv，避免在各处重复构造结果格式。
- 所有终端输出统一委托给 `printer.py` 的 `P.ok/P.fail/P.warn` 等函数，并通过 colorama 的 Fore/Style 常量包裹，保证 CLI 与 Web 捕获的输出风格一致。
- 变量替换采用 `${var}` 占位符配合 `_replace_deep` 递归遍历 dict/list/str，在 do_request/do_extract 之前先完成替换，确保后续逻辑拿到已解析的值。
- JSON 路径取值使用 `get_by_path` 统一处理点号键名与方括号数组下标（如 `items[0].name`），断言 json_path 与 extract 共享同一解析器。
- setup 前置条件通过受限命名空间 `_SETUP_SAFE_GLOBALS` 白名单 eval 计算表达式，每个变量独立 try/except，失败不影响其他变量计算。
- 可选第三方库（pandas、colorama、yaml）均采用运行时 import + ImportError 回退或静默降级策略，保证最小依赖也能运行。
